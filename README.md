# CodeSync Hub

## Overview
CodeSync Hub is a tool designed to streamline code deployments across multiple environments, providing automation for synchronization and rollback functionalities.

## Features
- Real-time code synchronization across environments
- Rollback functionality with version history
- User-friendly dashboard for deployment tracking
- Integration with popular CI/CD tools

## Installation
1. Clone the repository: `git clone https://github.com/yourusername/finggu-codesync-hub`
2. Navigate to the project directory: `cd finggu-codesync-hub`
3. Install dependencies: `npm install`
4. Set up your PostgreSQL database and configure the environment variable for DB_PASSWORD.
5. Start the application: `node src/index.js`

## Usage
Access the dashboard at `http://localhost:3000`.
